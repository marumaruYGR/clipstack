# 剪栈更新日志

## 1.1.4 · 2026-11-20

- 修复直接上屏将辅助功能、键盘事件和输入监听混为前置条件的问题，按实际所需权限判断可用性。
- 改进授权后的状态刷新，对比当前进程与新进程的检测结果，必要时提供可选的重启入口。
- 新增授权说明和仅针对剪栈的设备控制授权恢复，处理系统沿用旧构建签名的情况。
- 未授权时提示「直接上屏需要系统授权，你也可以使用手动粘贴。」，不把可选授权视为错误。
- 保留授权设置之前的目标应用，完善焦点恢复和手动粘贴回退，并提供不含剪贴内容的诊断信息。

## 1.1.2 · 2026-11-20

- 默认「直接上屏」，点选剪贴板、收藏夹或快捷收纳区的记录后，等待组合键释放、恢复原应用的编辑焦点，再发送 ⌘+V。系统授权不足时保留已复制内容，提示手动粘贴。
- 设置可切换「手动粘贴」。两种模式首次使用时各发送一次 macOS 通知。手动粘贴所选内容时显示短提示。
- 「清空全部」同步清空系统剪贴板和剪栈历史，收藏继续保留，同时撤销待粘贴状态和旧提示。
- 复制、选取和粘贴短提示加入各 0.5 秒的非线性进场与退场动画，可在设置关闭，遵循系统减少动态效果。
- 普通启动、登录自启动、重复启动及应用内重启均在菜单栏静默运行。单击打开快捷收纳区，主窗口从右键「显示主界面」、「查看全部」或 Dock「检索剪贴板」打开。
- 启动通知显示「剪栈已启动，正在后台运行。单击菜单栏图标打开快捷收纳区。」，设置可选择永久关闭。
- 收藏夹支持口令加密导出与导入，验证口令后确认合并，重复内容跳过。旧库无法解密时恢复到新目录并保留原文件。
- 关于页新增内置图文使用手册，包含使用说明、亮点、场景、常见问题与六张 macOS 界面配图，离线模态阅读。
- 设置新增检查更新、查看更新日志与下载并安装。后台每日检查，发现新版发送系统通知，安装由用户选择。检查期间显示「正在检查更新…」，安装包校验大小和 SHA-256。
- 主窗口显示时，预览以主窗口为中心，隐藏或最小化时以当前屏幕工作区为中心。
- 图片预览右键菜单精简为「复制图像」。长组合键在侧栏标题下按键名分组换行。
- 保留原生 Liquid Glass、静态卡片与独立相册预览、实时搜索、登录会话历史、钥匙串加密收藏和原生亮暗分层图标。
